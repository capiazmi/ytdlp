      Install & share shortcuts
      

        
Android (Chrome)

        
Menu ⋮ → Install app. Then in the YouTube app tap Share → ytdlp and the link opens here ready to go.

        
iPhone / iPad (Safari)

        
Share → Add to Home Screen. iOS doesn't let web apps appear in the share sheet, so create a Shortcut:
          
    
            
  1. Shortcuts app → + → name it “ytdlp”.
    2. 
            
  2. Tap the ⓘ → enable Show in Share Sheet, accept URLs.
    3. 
            
  3. Add URL Encode (input: Shortcut Input).
    4. 
            
  4. Add Open URLs with: [URL Encoded Text]
    5. 
          

          Now YouTube → Share → More → ytdlp.

        
Desktop

        
Drag this to your bookmarks bar, then click it on any YouTube page: ⤓ ytdlp
